# notes/ 저장 규약 (기록의 기준 문서)

이 폴더는 텔레그램으로 던진 메모가 **분류되어 쌓이는 곳**입니다.
`quick-note`(저장) · `recall`(회상) · `import-sort`(들여오기)가 **똑같이 이 규약을 따릅니다.**

## 폴더는 고정 목록이 아닙니다

설치 직후엔 **두 개**만 있습니다. 나머지는 **각자 자기 일에 맞게** 만듭니다.

| 폴더 | 무엇 | 왜 기본인가 |
|---|---|---|
| `inbox/` | 분류가 애매한 것 **전부**. 여기서 시작합니다 | 어디 넣을지 고민하다 안 남기는 게 제일 나쁩니다 |
| `issues/` | **아직 안 끝난 문제** | **유일하게 기능이 걸린 폴더**입니다 — 아침 브리핑이 여기를 봐서 놓친 걸 꺼냅니다 |

나머지는 자유입니다. 폴더 이름은 **당신의 말**이어야 합니다:

```
사업을 한다면     고객사/  미팅/  아이디어/
프로젝트를 굴린다면  회의/  산출물/  아이디어/
여러 갈래를 굴린다면  본업/  자격증/  영상/       ← 갈래 이름 그대로
```

> 예전 버전은 `inbox · meetings · customers · ideas · issues` 다섯 개가 고정이었습니다.
> **`customers`(고객)라는 이름이 모두에게 맞지 않아서** 고정을 걷어냈습니다 — 자격증을 준비하는
> 사람에게 스터디 멤버가 "고객"으로 분류되는 건 틀린 말입니다.
> 이미 그 다섯 폴더를 쓰고 계셨다면 **그대로 두셔도 됩니다.** 화면은 있는 폴더를 그대로 보여줍니다.

## 폴더를 새로 만들 때

**사람이 직접 만들어도 되고, 파트너에게 시켜도 됩니다.** 파트너는 이렇게 움직입니다:

- 마땅한 폴더가 없으면 **먼저 `inbox/`** 에 넣습니다. 임의로 폴더를 만들지 않습니다.
- 한 갈래가 눈에 띄게 쌓이면 **먼저 제안합니다** — *"'영상' 관련 기록이 8건 됐어요. `영상/` 으로 따로 뺄까요?"*
- 승낙하면 폴더를 만들고 해당 기록을 옮깁니다.

## 파일명 규칙

```
YYYY-MM-DD-짧은제목.md
```

예: `2026-07-20-A업체-단가조정.md`, `2026-06-30-실기-접수.md`

- 날짜는 **기록한 날**. 같은 날 같은 주제가 이어지면 같은 파일에 이어 적습니다.
- 제목은 나중에 찾기 쉬운 핵심어로 짧게.
- **다른 곳에서 들여온 기록**(`import-sort`)도 같은 규칙입니다 — 옮긴 날이 아니라 **원본이 기록된 날**을
  씁니다. 3월에 오간 카톡을 8월에 들여왔으면 파일명은 `2026-03-…` 입니다. 그래야 "지난달 그 건"으로
  찾을 수 있습니다. 원본에 날짜가 없으면 파일 수정일을 쓰고, 그것도 없으면 들여온 날을 쓰되
  **본문에 그렇게 밝힙니다.**

## 파일 안 형식 (권장)

```markdown
# 짧은제목

- 날짜: 2026-07-20 14:30
- 분류: 고객사
- 태그: A업체, 단가

본문 — 던진 메모 원문 + 파트너가 정리한 요약.
```

## `_import/` — 원본 보관함 (`notes/` 바깥입니다)

다른 곳에서 가져온 **원본을 그대로 두는 곳**이고 `notes/` **바깥**에 있습니다.
`import-sort` 스킬이 여기를 읽어 `notes/` 로 정리해 넣습니다.
**원본은 지우지 않고, 회상(`recall`)은 `_import/` 를 검색하지 않습니다** — 원본과 정리본이 둘 다
걸리면 같은 사실이 두 번 나오기 때문입니다.

> 참고: `projects/` 폴더는 **project-team 스킬 전용** 산출물 폴더입니다
> (`projects/<YYYY-MM-프로젝트슬러그>/01-단계.md`). 각 프로젝트 폴더에는 단계별 산출물과 함께
> 완료 시 **`99-최종종합.md`**(최종 종합)와 **`99-회고.md`**(잘된 것/막힌 것/다음에 다르게 — 각 3줄)가
> 남습니다. 이 회고는 다음 프로젝트 착수 때 각 역할이 recall 로 훑어 경험이 축적됩니다.
> quick-note가 분류해 넣는 곳이 아니며, recall은 여기도 함께 검색합니다.

> 이 규약은 `CLAUDE.md`, `.claude/skills/quick-note/SKILL.md`, `.claude/skills/recall/SKILL.md`,
> `.claude/skills/import-sort/SKILL.md` 에서 동일하게 참조합니다.
> 경로 표기(`notes/<폴더>/<파일>.md`)를 바꾸지 마세요.
