# 캘린더 연결하기 (선택 — 안 해도 됩니다)

> 📄 **이 문서는 손으로 할 때 쓰는 백업입니다.** 권장 경로는 터미널에서 `claude` 를 켜고
> **"캘린더 연결해줘"** 라고 말하는 것입니다. 코치(`setup-calendar` 스킬)가 준비물 확인부터
> 결과 확인까지 데려갑니다.

캘린더를 연결하면 **텔레그램 브리핑과 대시보드가 같은 일정을 봅니다.**
연결이 어렵거나 시간이 없으면 아래 B·C 로도 브리핑을 그대로 체험할 수 있습니다 —
워크숍 진행이 캘린더 연동에 묶이지 않습니다.

| 방법 | 무엇이 되나 | 필요한 것 |
|---|---|---|
| **A (권장)** | 일정 **읽기 + 쓰기**. 화면에서 만들고 고치고 지울 수 있다 | 구글 로그인 **1회** |
| B | 대시보드에서 **보기만** | ICS 비밀 주소 복사 |
| C | 브리핑만 (수기 파일) | 없음 |

---

## 방법 A (권장) — 구글 캘린더 실연동

**하실 일은 구글 로그인 한 번뿐입니다.** 나머지(클라우드 프로젝트 만들기 · 캘린더 API
켜기 · 동의 화면 · 앱 열쇠 발급 · 앱 게시 · 권한 승인 · 읽기·쓰기 확인)는 파트너가 자동으로 합니다.

파트너에게 **"캘린더 연결해줘"** 라고 말하세요. 손으로 하려면:

```bash
node tools/google-connect/connect.mjs            # 연결 (중간부터 이어서도 됩니다)
node tools/google-connect/connect.mjs --show     # 지금 어디까지 됐는지
node tools/google-connect/connect.mjs --verify   # 연결이 살아 있는지
```

- 크롬 창이 열리면 **거기서 구글 로그인만** 하면 됩니다. 평소 쓰는 크롬과 별개 창이라
  기존 로그인·북마크는 건드리지 않습니다.
- 중간에 멈춰도 **처음부터 다시 하지 않습니다** — 다음에 실행하면 된 곳부터 이어갑니다.
- 필요한 것: 크롬 · Node(`node -v`). 없으면 코치가 그때 설치를 안내합니다.

**연결되면 이렇게 됩니다**

- 텔레그램 **"내일 일정 브리핑해줘"** → 실제 캘린더 일정으로 답합니다.
- 텔레그램에서 **일정을 바꿔 달라고 해도 됩니다** — "금요일 2시에 A업체 미팅 잡아줘",
  "3시 미팅 4시로 옮겨줘", "그 일정 취소해줘". 지운 뒤에는 **되돌릴 수 있습니다.**
  (고치거나 지우기 전에는 한 번 확인을 받습니다.)
- 대시보드 홈의 **월 격자**에 일정이 뜨고, **날짜를 눌러 새 일정을 만들 수 있습니다.**
  일정을 눌러 고치거나 지울 수 있고, 지운 직후 5초 안에 **되돌리기**가 뜹니다.
- 구글 캘린더 사이드바에서 **켜 둔 캘린더만** 가져옵니다. 안 보이는 캘린더가 있으면
  구글에서 그 캘린더의 체크를 켜면 화면에도 나타납니다.

**고칠 수 없는 일정도 있습니다 — 정직하게 말씀드립니다**

공휴일 캘린더나 남이 **읽기 전용으로 공유**해 준 캘린더는 화면에서 못 고칩니다.
우리 권한 문제가 아니라 **구글이 막는 것**입니다(그 캘린더에는 구글 캘린더 앱에서도 못 씁니다).
그런 일정을 누르면 편집창 대신 *"'○○' 은 읽기 전용이에요"* 라고 알려 드립니다.
고쳐야 한다면 그 캘린더 소유자에게 **'일정 변경' 권한**을 받으면 됩니다.

**권한 범위**: 캘린더 일정 읽기·쓰기 + 캘린더 목록 읽기. 메일·연락처는 보지 않습니다.
연결 열쇠는 `state/google-calendar.json` 에 저장되고 **이 폴더 밖으로 나가지 않습니다.**

## 방법 B — ICS 비밀 주소 (로그인 없이 보기만)

로그인 없이 대시보드에서 일정을 **보기만** 하면 될 때 씁니다.

1. 구글 캘린더(웹) → 오른쪽 위 ⚙️ **설정** → 왼쪽에서 연결할 캘린더 선택.
2. **'iCal 형식의 비밀 주소'** 를 복사합니다 (`https://calendar.google.com/calendar/ical/…/basic.ics`).
3. 파트너에게 **"캘린더 연결해줘"** 라고 하고 주소를 붙여넣으면 `state/calendar.json` 에 저장합니다.
4. `./dashboard.sh` 로 대시보드를 열면 일정이 뜹니다 (10분마다 갱신).

> ⚠️ **비밀 주소는 비밀입니다** — 아는 사람은 누구나 일정을 볼 수 있습니다. 다른 곳에 붙여넣지 마세요.
> 이 방법은 **보기 전용**입니다. 화면에서 일정을 만들거나 고칠 수는 없습니다.

## 방법 C — 수기 일정 파일 (연결 없이 브리핑만)

연결이 막히거나 시간이 부족해도 괜찮습니다. 아래 파일에 이번 주 일정을 적으면
브리핑이 **캘린더 대신 이 파일을 읽어** 똑같이 답합니다.

```
notes/calendar-fallback.md
```

1. 파일을 엽니다 (설치할 때 예시가 들어 있습니다).
2. 예시를 지우고 **아무 형식으로나** 이번 주 일정을 적습니다:

   ```
   ## 이번 주 일정
   - 월 10:00 A업체 미팅 (단가 재협의)
   - 화 15:00 B고객 코칭
   - 목 11:00 세무사 통화
   ```

3. 텔레그램에 **"내일 일정 브리핑해줘"** 라고 하면 이 파일 기준으로 답합니다.

---

## 브리핑은 어느 것을 보나 — 순서

**① 구글 실연동(A)이 있으면 그것 → ② 없으면 ICS(B) → ③ 그것도 없으면 수기 파일(C)**

브리핑과 대시보드가 **같은 창구**를 쓰므로, 연결하면 양쪽이 같은 일정을 봅니다.
같은 규약이 `.claude/skills/daily-briefing/SKILL.md` 에도 적혀 있습니다.
어느 경로든 브리핑 결과의 형식은 같습니다.
